# Route And Download Workflow

1. Create or update a `downloadFile`.
2. Set file type, version, publication date, and notes.
3. Attach the Sanity file asset or provide an external URL.
4. Reference the download from a `route` or `trailSegment`.
5. Preview the affected map and page.
6. Publish only after confirming labels and file freshness.

Recommended labels include `Full Trail GPX`, `Route Overlay KML`, `GIS Shapefile`, and route-specific day or segment files.
